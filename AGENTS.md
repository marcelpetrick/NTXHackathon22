## What this is

Cleaned-up leftovers of the **NeuroTechX Hackathon 2022** (29/30 Oct 2022, most likely the
Munich hub). The team (Shuhong Huang `@sh2huang`, Thomas Mullen `@ThomasMullen`, Marcel
Petrick) recorded EEG with an **OpenBCI Ganglion** (4 EXG channels, 200 Hz, BLE) to steer a
one-row Pacman by blinks. The repo is now the `ntxbci` Python package: loaders, manifest,
processing, blink detection, epoching, spectra, replay check, CLI, web dashboard, game.
The original upstream repo (`Timbrer/NTXHackathon22`) and the team's Google Doc are gone;
open questions about the protocol are in issue #1.

## Data facts (reconstructed 2026-10-14, encoded in `Recordings/manifest.json`)

- Column layout (all formats): `0` sample/packet index, `1–4` EXG (µV), `5–7` accelerometer,
  `8–12` other, `13` unix timestamp, `14` BrainFlow **marker channel** — all zero everywhere:
  **no recording has event markers**.
- `BrainFlow-RAW_session{2,3,4}_1.csv` are **impedance checks** (packet IDs 201–205, cols 8–12),
  each taken 9–20 s *before the next* session, i.e. misfiled one folder early. Values are
  electrode + driven ground in kΩ; the GUI shows half (`io.electrode_impedance`).
- `session5`'s BrainFlow CSV duplicates its GUI export.
- `stimulus_order.txt`: 14 binary labels, no timing, meaning unknown. Any epoching must state
  its `TrialTiming` explicitly; `scan_timing` results are exploratory only.
- Blink test (2022-10-30): 10 s rest then a blink every 5 s → the only ground truth.
  The detector must keep F1 = 1.0 on it (`tests/integration/test_processing_real.py`).
- Every stream starts with a ~3 s amplifier transient; raw sessions carry strong 50 Hz mains.
- Afternoon runs (14:06–16:10) were deleted in `f1374da` (bad contact); recover with
  `git show f1374da^:<path>`.

## Commands

```bash
uv sync --all-extras                 # setup
./localPipeline.sh                   # THE gate (CI runs exactly this); --fast skips e2e+docker
scripts/commit.sh patch "type(scope): msg" -- new/file.py   # bump -> pipeline -> commit -> push
uv run ntxbci replay blink-test      # end-to-end regression check
uv run python scripts/screenshots.py # refresh README screenshots after UI changes
uv run python scripts/make_video.py --gif  # showcase clips -> build/video/ (needs ffmpeg)
```

Headless pygame: `SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy` (the pipeline exports them).

## Rules

- Work on `main`; atomic conventional commits; **every commit bumps the version** (patch;
  minor for a major feature) — use `scripts/commit.sh`, which never commits a red pipeline.
- Keep coverage ≥ 95 % (currently ~99 %), `mypy --strict` clean, ruff clean.
- Every `.py`/`.sh`/`Dockerfile` needs the SPDX header (`scripts/check_headers.sh`); every
  script needs a `# <name> - <purpose>` line and an entry in `scripts/README.md`.
- Raw files in `Recordings/` are the historical record: never modify or reformat them. If you
  add a recording, add it to `manifest.json` — `verify()` fails on unlisted files.
- Game rules stay pure (`game/model.py` must not import pygame) so replay/CI work headless.
  Game balance is pinned by `test_balance_blink_cadence_wins_idle_loses`.
- The docker image must keep passing `scripts/docker_smoke.sh` (healthz, API, plot, replay).
- After UI changes regenerate `docs/media/` and check the screenshots visually.
